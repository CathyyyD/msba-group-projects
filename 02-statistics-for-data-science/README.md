# Do Extracurriculars Raise Test Scores?

**Course:** BANA 201 · Statistics for Data Science · Summer II 2025

Tested whether extracurricular participation affects average test scores across 2,000 students, using a Welch's t-test and a multiple regression to control for weekly study hours and absences.

**Key result:** No significant effect from extracurriculars (β = −0.064, p = 0.825) once study habits (β = +0.236, p < 0.001) and absences (β = −0.224, p < 0.001) were controlled for. Model R² = 0.26.

**Tools:** Python, pandas, statsmodels/scipy (Welch's t-test, OLS regression)
